# BrickWorld source code

The source of the BrickWorld apps, GNU GPL v3 (see [LICENSE](../LICENSE)). The ready-to-use zips are in [`downloads/`](../downloads/).

- [`bricksampler/`](bricksampler/) – BrickSampler 2.0.3. `bricksampler/bricksampler.py` is the app (Python, Pygame, NumPy), `bricksampler/native/bsdsp.c` the audio engine (voices, loops, LFO, wave sequences, FX, ALSA output); `bricksampler/native/build.sh` builds `libbsdsp_aarch64.so` with zig. The zip also has the built library, NumPy (BSD) and the DejaVu fonts. Changes: [`bricksampler/CHANGELOG.md`](bricksampler/CHANGELOG.md).
- [`bricktape/`](bricktape/) – BrickTape 1.1.2. `bricktape/bricktape.py` is the app (Python, Pygame, NumPy), `bricktape/native/btdsp.c` the audio engine; `bricktape/native/build.sh` builds `libbtdsp_aarch64.so` with zig. The zip also has the built library, NumPy (BSD) and the DejaVu fonts.
- [`bricklooper/`](bricklooper/) – BrickLooper 1.5.2. `bricklooper/bricklooper.py` is the app (Python, Pygame, NumPy), `bricklooper/native/bsdsp.c` the audio engine; `bricklooper/native/build.sh` builds `libbsdsp_aarch64.so` with zig. The zip also has the built library, NumPy (BSD) and the DejaVu fonts.
- [`brickambientfx/`](brickambientfx/) – BrickAmbientFX (Sarta Edition) 1.0.0. `brickambientfx/brickambientfx.py` is the app (Python, Pygame, NumPy), `brickambientfx/native/bafx.c` the audio engine; `brickambientfx/native/build.sh` builds `libbafx_aarch64.so` with zig. The zip also has the built library and NumPy (BSD). Changes: [`brickambientfx/CHANGELOG.md`](brickambientfx/CHANGELOG.md).
- [`brickfx/`](brickfx/) – BrickFX 1.0.2. `brickfx/brickfx.py` is the app (Python, Pygame, NumPy), `brickfx/native/bfx.c` the audio engine (USB input, drift resampler, effect chain, ALSA output); `brickfx/native/build.sh` builds `libbfx_aarch64.so` with zig. The zip also has the built library and NumPy (BSD). Changes: [`brickfx/CHANGELOG.md`](brickfx/CHANGELOG.md).
